## 🚀 Featured Projects

### 🦾 Robotic Automation Cell — Bachelor Thesis
Full robotic cell designed from scratch: articulated arm, custom gripper with **topology optimization**, assembly fixtures, and intermediate positioning components. Integrated MoveIt 2 trajectory planning on ROS2 on the physical prototype.  
`SolidWorks` · `MoveIt 2` · `ROS2 Humble` · `FDM` · `Topology Optimization`  
🔗 [View repository](https://github.com/TU-USUARIO/TFG-robotic-cell)

---

### 🤖 Franka Emika Workcell — MuJoCo Simulation
Full collaborative robot workcell modelled in MuJoCo via URDF/Xacro for accurate dynamics simulation and motion validation prior to hardware deployment.  
`MuJoCo` · `URDF/Xacro` · `ROS2` · `Python`  
🔗 [View repository](https://github.com/TU-USUARIO/franka-mujoco-workcell)

---

### 🧭 AGV Autonomous Navigation — Nav2
Deployed Nav2 on a real AGV rover for autonomous indoor navigation and part transport in a live lab environment. Includes SLAM-based mapping, localization, and path planning.  
`Nav2` · `ROS2 Humble` · `SLAM` · `Python`  
🔗 [View repository](https://github.com/TU-USUARIO/agv-nav2)
